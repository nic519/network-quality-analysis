# Latency Compass 核心原理

## 概述

Latency Compass 是一个基于 `clash-speedtest` 的代理节点延迟和速度测试工具，用于批量测试 Clash/Mihomo 代理配置中各节点到目标网站的访问质量。

## 工作流程

1. **输入 Clash/Mihomo 配置**（本地配置文件路径或订阅 URL）
2. **选择测试地区**（香港/日本/新加坡/美国/台湾）
3. **选择目标测试网站**（YouTube / X / GitHub）
4. **调用 `clash-speedtest` 批量测**

## 核心机制

```
clash-speedtest -c <config> -f <region-filter-regex> --speed-mode fast --latency-url <site-url>
```

| 参数 | 含义 |
|------|------|
| `-c` | Clash/Mihomo 配置文件路径或 URL |
| `-f` | 节点名称正则过滤（如 `HK\|港\|香港` 匹配所有香港节点） |
| `--speed-mode fast` | 快速测速模式 |
| `--latency-url` | 目标测试 URL |

## 地区过滤规则

| 地区 | 正则表达式 |
|------|-----------|
| 香港 | `HK\|港\|香港\|Hong Kong\|HongKong` |
| 日本 | `JP\|日\|日本\|Japan\|Tokyo\|大阪\|东京` |
| 新加坡 | `SG\|新加坡\|狮城\|Singapore\|Singa` |
| 美国 | `US\|USA\|美\|美国\|United States\|America\|Los Angeles\|San Jose\|Seattle\|New York` |
| 台湾 | `TW\|台\|台湾\|臺灣\|Taiwan\|Taipei\|台北\|臺北` |

## 核心价值

**本质：让所有匹配过滤规则的节点通过各自的出口 IP 访问目标网站，测试每个节点的延迟和速度。**

应用场景：
- 快速找出最快的代理节点
- 对比不同地区节点的质量差异
- 批量验证多个站点的访问性能
